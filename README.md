# Qibray 13-Maktab Rasmiy Portali (React + Vite + Tailwind CSS)

## Ishga tushirish

1. ZIP arxivni oching va papkaga kiring:
```bash
cd qibray-13-maktab-portal
```

2. Paketlarni o'rnating:
```bash
npm install
```

3. Loyihani ishga tushiring:
```bash
npm run dev
```

## Xususiyatlar
- **Interactive Welcome Gate**: Saytga kirganda maxsus animatsion kirish ekrani (va Navbar orqali qayta ko'rish tugmasi).
- **4 Tilda Interface**: O'zbek (`UZ`), Rus (`RU`), Ingliz (`ENG`) va Qozoq (`QAZ`).
- **Dark / Light Mode**: To'liq tungi va kunduzgi rejim.
- **Zamonaviy arxitektura**: `pages/`, `components/`, `layout/`, `context/`, `services/api.js` (Axios), `react-hook-form`, `react-router-dom`.
